# Not in DS3.0

Temporary components for things DS3.0 doesn't have yet.

- Name each file after what it is, for example `Timeline.tsx`.
- Build it from DS3.0 pieces (`Stack`, `Typography`, `Card`) and tokens where possible.
- Every file here is a gap in the design system. Share the list with the DS owner.
- `AddToChatMenu.tsx` is the menu that appears when text in the right column is highlighted.
- `TruncatedChip.tsx` is a chip or tag whose label stays on one line and ends with an ellipsis when it runs out of room.
